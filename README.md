# Riski's Portfolio Website

Hey! Welcome to the repo for my personal website: [riskilinardi.vercel.app](https://riskilinardi.vercel.app/). 

I'm a Software Engineer based in Singapore focusing on ML, AI, and full-stack development. I built this site to keep track of what I'm working on and to share my projects in one place.

## Built with
- Next.js / React
- Tailwind CSS
- Vercel for hosting

## What's on here?
If you check out the site, you'll see a few of my main projects, including:
- **Trackery:** A desktop inventory app built with Electron, React, Node.js, and Postgres. I also set it up with Tailscale for zero-trust networking.
- **Fake News Classifier:** A BERT microservice (PyTorch + FastAPI) that actually explains its predictions at the token level. 
- **TogetherSafe:** An emergency coordination mobile app I built with Flutter.
